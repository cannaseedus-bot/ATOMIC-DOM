MX2LM Server Panel Demo

This page demonstrates the MX2LM CSS Micronaut UI Panel. The panel in the bottom-right corner updates automatically via WebSocket when the server is running.

Start the server with: node server.khl

The panel's appearance is driven entirely by CSS custom properties:

  • --mx2lm-health - Controls opacity and health bar fill
  • --mx2lm-uptime - Seconds since server start
  • --mx2lm-traffic - Normalized request rate (0-1)
  • --mx2lm-glow - Activity glow intensity
